# python-calculator
A text-based scientific calculator built in Python that can perform basic arithmetic as well as scientific functions.
Designed for beginners to learn Python programming and math operations.

# Features

Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Power (x^y)
Square root (√x)
Trigonometry: sin, cos, tan (input in degrees)
Logarithms: log (base 10)

# How to run
Run the python file and enter inputs
